# MiniLink IDS — Детектор сетевых атак

Учебный проект: уязвимая мини-соцсеть (MiniLink) + система обнаружения вторжений (IDS) на основе машинного обучения.

## 🏗 Архитектура

- **target-site** — уязвимая мини-соцсеть (FastAPI + PostgreSQL). Генерирует трафик.
- **attack-generator** — бот, который имитирует нормальное поведение и запускает атаки (DDoS, брутфорс, спам).
- **collector.py** — сниффер (Scapy), который собирает сетевые потоки и сохраняет их в CSV для обучения.
- **ML** — модель RandomForest, которая классифицирует трафик на «нормальный» и «атаку».

## ⚔️ Генерация трафика

Все команды запускаются из корня проекта.

**Нормальный трафик (30 секунд):**
```bash
make normal
```

**HTTP Flood (DDoS):**
```bash
make flood DURATION=15 CONCURRENCY=50
```

**Брутфорс паролей:**
```bash
make brute USER=alice ATTEMPTS=500
```

**Накрутка лайков:**
```bash
make likes USER=bob POST_ID=1 COUNT=500
```

**Slowloris (медленная атака):**
```bash
make slowloris DURATION=30 CONNECTIONS=100
```

## 📊 Сбор данных для ML

1. **Собрать нормальный трафик:**
   - В первом терминале: `make collect-benign`
   - Во втором терминале: `make normal DURATION=60`
   - Подождите 10 секунд, нажмите `Ctrl+C` в первом терминале.

2. **Собрать атакующий трафик:**
   - В первом терминале: `make collect-attack`
   - Во втором терминале: `make flood` + `make brute` + `make likes`
   - Подождите 10 секунд, нажмите `Ctrl+C` в первом терминале.

3. **Скопировать данные в папку ML:**
```bash
make copy-flows
```

## 🧠 Обучение модели

```bash
make install-ml
make train
```
После этого в папке `ml/` появится файл `model.pkl`.

## 🛠 Полезные команды

- `make help` — список всех команд.
- `make ps` — статус контейнеров.
- `make logs` — логи всех сервисов.
- `make shell` — зайти внутрь `target-site`.
- `make psql` — зайти в базу данных PostgreSQL.
- `make reset` — полностью удалить контейнеры и данные (осторожно!).
- `make admin USER=alice` — выдать права администратора.

## ⚠️ Важно

- Для работы `collector.py` контейнеру `target-site` нужны права `NET_ADMIN` и `NET_RAW` (уже добавлены в `docker-compose.yml`).
